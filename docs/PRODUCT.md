# 短视频去水印（ShortVideo NoWatermark）

## 是什么
一个纯本地运行的 Android 去水印工具：粘贴抖音 / 快手 / 小红书 / B 站分享链接，
在手机内解析出无水印视频、图集或音频，并保存到相册。没有账号、没有自建服务端。

## 用户与场景
- 普通用户刷到想收藏的视频，复制链接后 3 步内拿到无水印文件。
- 弱网/隐私敏感用户：不希望链接经过第三方服务器。
- 附带工具：去背景音乐、提取音频、音频转码、视频局部涂抹、裁剪。

## 成功标准
- 粘贴链接 → 预览 → 保存，全程不跳浏览器、不登录。
- 解析失败时给出人话原因，不白屏。
- 赞赏入口不打断主流程。

## 约束
- 仅 Android（minSdk 26）；Kotlin + Compose + Media3 + FFmpegKit。
- 单 APK，无后端依赖；解析逻辑全部在 `parser/`。
- 视觉：浅色液态玻璃（Apple 系），离线字体，不引入需要联网的素材。
